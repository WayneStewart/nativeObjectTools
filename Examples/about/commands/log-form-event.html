Log Form Event

Log Form Event -> Text

Returns text describing the current form event.

Shared, Invisible, Preemptive incapable

This is useful when instrumenting form methods and wanting readable event names in the log rather than raw event codes.

Parameters

ParameterTypeDescription
ResultTextThe current form event description.

Code examples

Log a form event

$event_t:=Log Form Event
LOG ADD ENTRY(Current method name; "Form event"; $event_t)
