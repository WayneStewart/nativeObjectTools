Public API

Log Current Log

Log Current Log -> Text

Returns the current process log file name.

Shared, Invisible, Preemptive capable

This reports the file name resolved for the current process. It does not return the label.

Parameters

ParameterTypeDescription
ResultTextThe current physical log file name.

Code examples

Report the active file

$file_t:=Log Current Log
LOG ADD ENTRY("Current log file"; $file_t)
