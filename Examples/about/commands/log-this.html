LOG THIS

LOG THIS (Log entry; Log folder; Log file name {; Flush now {; Flush milliseconds {; Report batch}}})

Buffers the current log entry inside the Log Writer worker. The buffer is written when its policy or thresholds require a flush.

Private, Invisible, Preemptive capable

Buffers the current log entry inside the Log Writer worker. The buffer is written when its policy or thresholds require a flush.

This method is an implementation detail used by the public API, documentation tooling, build process, or test harness. Application code should prefer the public API unless this project is being maintained directly.

Parameters

ParameterTypeDescription
$1TextLog entry
$2TextLog folder
$3TextLog file name
$4BooleanFlush this log immediately after appending this entry - optional
$5IntegerFlush interval in milliseconds. 0 means real time - optional
$6BooleanAppend batch diagnostic entries when flushing - optional
