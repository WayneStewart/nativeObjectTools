Private, Invisible, Preemptive capable

Process state isn't thread safe. Because of the deprecation of PROCESS PROPERTIES in 20r7 this method is designed to work around this by calling either PROCESS PROPERTIES or Process Info

This method is an implementation detail used by the public API, documentation tooling, build process, or test harness. Application code should prefer the public API unless this project is being maintained directly.
