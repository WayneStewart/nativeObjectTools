Public API

Log Current Label

Log Current Label -> Text

Returns the active process log label.

Shared, Invisible, Preemptive capable

Use this when you need to report or restore the selected label. It returns a label, not a file name.

Parameters

ParameterTypeDescription
ResultTextThe current label, or empty text when the process is using the default log or a direct file/folder selection.

Code examples

Log the current label

$label_t:=Log Current Label
LOG ADD ENTRY("Current label"; $label_t)
