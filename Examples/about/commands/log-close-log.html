Public API

LOG CLOSE LOG

LOG CLOSE LOG({Log Label})

Flushes and closes one named log, or all open logs.

Shared, Invisible, Preemptive capable

Use this when a log file must be complete and closed before another process reads, moves, or archives it. Closing all logs clears the writer's open document references and buffers.

Parameters

ParameterTypeDescription
Log LabelTextOptional log label. If omitted, all logs are flushed and closed.

Code examples

Close all logs

LOG FLUSH
LOG CLOSE LOG
