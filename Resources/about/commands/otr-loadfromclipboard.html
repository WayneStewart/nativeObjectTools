OTr_LoadFromClipboard

ObjectTools equivalent: OT LoadFromClipboard

OTr_LoadFromClipboard () --> Longint

Shared, Invisible, Preemptive indifferent

Reads a JSON string from the system clipboard and loads it into a new OTr handle.

Returns 0 if the clipboard contains no text or invalid JSON.

NOTE: there is no equivalent Object Tools command

Parameters

ParameterTypeDirectionDescription
ResultInteger⬅️New OTr handle, or 0 if loading failed
