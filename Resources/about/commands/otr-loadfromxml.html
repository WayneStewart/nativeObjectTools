OTr_LoadFromXML

ObjectTools equivalent: OT LoadFromXML

OTr_LoadFromXML (inXML) --> Longint

Shared, Invisible, Preemptive indifferent

Parses an XML string (written by OTr_SaveToXML) using DOM and loads the reconstructed object into a new OTr handle.

Returns 0 if inXML is empty or cannot be parsed.

Delegates all reconstruction to OTr_z_XMLReadObject.

See OTr_SaveToXML for a description of the XML schema.

Shadow-type keys present in the XML are always restored, regardless of the current OTr_IncludeShadowKey setting, so that round-trip fidelity is preserved for files that were written with shadow keys included.
