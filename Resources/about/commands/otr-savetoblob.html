OTr_SaveToBlob

ObjectTools equivalent: OT SaveToBlob

OTr_SaveToBlob (inObject) --> Blob

Shared, Invisible, Preemptive indifferent

Changed behaviour

The output format of this method differs from the ObjectTools plugin equivalent. Text or BLOBs produced by one are not compatible with the other. See the description below for details.

Serialises the stored object to a compressed 4D-native blob using VARIABLE TO BLOB and GZIP compression. The format is 4D-internal and is not portable outside 4D. Use OTr_SaveToGZIP when portability across systems is required.

Parameters

ParameterTypeDirectionDescription
inObjectInteger➡️OTr inObject
ResultBlob⬅️Compressed 4D-native blob, or empty blob if the handle is invalid
