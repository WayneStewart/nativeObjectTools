Array operations

OTr_ArrayType

ObjectTools equivalent: OT ArrayType

OTr_ArrayType (inObject; inTag) --> Longint

Shared, Invisible, Preemptive indifferent

Returns the stored arrayType value from an OTr array object. Used to verify type compatibility before performing array operations.

Returns -1 if the handle is invalid, the tag does not exist, or the tag does not reference an array.

Parameters

ParameterTypeDirectionDescription
