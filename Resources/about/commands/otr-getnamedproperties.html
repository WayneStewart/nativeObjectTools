Item operations

OTr_GetNamedProperties

ObjectTools equivalent: OT GetNamedProperties

OTr_GetNamedProperties (inObject; inTag; outType {; outItemSize {; outDataSize {; outIndex}}})

Shared, Invisible, Preemptive indifferent

Returns properties of the item identified by $inTag_t: its type constant, approximate item size, approximate data size, and index (always 0; reserved for compatibility).

Parameters

ParameterTypeDirectionDescription
inObjectInteger➡️OTr inObject
inTagText➡️Tag of the item to query (inTag)
outTypePointer⬅️Receives OT type constant (Longint)
outItemSizePointer⬅️Receives item size including tag
outDataSizePointer⬅️Receives item data size (Longint)
outIndexPointer⬅️Always set to 0 (Longint) (optional)
