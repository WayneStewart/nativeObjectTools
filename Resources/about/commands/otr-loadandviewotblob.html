OTr_LoadAndViewOTBlob

ARRAY TEXT($paths_at; 0)

look up file $Options_i:=Allow alias files+Package open+Use sheet window $FolderPath_t:=System folder(Desktop) //$DocumentName_t:=Select document($FolderPath_t; ""; "Select a Blob"; $Options_i; $paths_at)

$DocumentName_t:=Select document(23; ""; "Select a Blob"; $Options_i; $paths_at)

Import the blob If ($DocumentName_t#"") Get the path $DocumentPath_t:=String($paths_at{1})

DOCUMENT TO BLOB($DocumentPath_t; $import_blob)

$newHandle_i:=OTr_BLOBToObject($import_blob)

If ($newHandle_i=0) ALERT("Something went wrong")

Else OTr_ObjectViewer

End if

End if

Parameters

This method takes no parameters.
