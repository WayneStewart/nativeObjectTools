OTr_SaveToGZIP

No ObjectTools 5.0 equivalent

OTr_SaveToGZIP (inObject {; inPrettyPrint}) --> Blob

Shared, Invisible, Preemptive indifferent

Serialises the stored object to a UTF-8 JSON string and compresses it with GZIP, returning the result in a blob.

Suitable for compact network transmission or file storage where portability outside 4D is required.

Parameters

ParameterTypeDirectionDescription
inObjectInteger➡️OTr inObject
inPrettyPrintBoolean➡️True for indented output; \
ResultBlob⬅️GZIPed JSON blob, or empty blob if the handle is invalid
