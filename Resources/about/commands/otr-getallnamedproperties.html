OTr_GetAllNamedProperties

ObjectTools equivalent: OT GetAllNamedProperties

OTr_GetAllNamedProperties (inObject; inTag; outNames {; outTypes {; outItemSizes {; outDataSizes}}})

Shared, Invisible, Preemptive indifferent

Returns information about all items in the object (or embedded object).

$outNames_ptr must point to a Text array; the optional pointer params must point to Longint arrays. Internal __otr_ properties are excluded.

Item names are returned in indeterminate order.

Parameters

ParameterTypeDirectionDescription
inObjectInteger➡️OTr inObject
inTagText➡️Tag of an embedded object; empty for root (inTag)
outNamesPointer⬅️Receives item names (Text array)
outTypesPointer⬅️Receives OT type constants (Longint array)
outItemSizesPointer⬅️Receives item sizes in bytes
outDataSizesPointer⬅️Receives data sizes in bytes
