OTr_LoadFromFile

ObjectTools equivalent: OT LoadFromFile

OTr_LoadFromFile (inFilePath) --> Longint

Shared, Invisible, Preemptive indifferent

Reads a UTF-8 JSON file from disk and loads it into a new OTr handle. The file must have been written as a plain UTF-8 JSON text file (e.g. by OTr_SaveToFile).

NOTE: there is no equivalent Object Tools command

Parameters

ParameterTypeDirectionDescription
inFilePathText➡️Full path of the source file
ResultInteger⬅️New OTr handle, or 0 if loading failed
