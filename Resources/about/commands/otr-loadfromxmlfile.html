OTr_LoadFromXMLFile

No ObjectTools 5.0 equivalent

OTr_LoadFromXMLFile (inFilePath) --> Longint

Shared, Invisible, Preemptive indifferent

Reads a UTF-8 XML file from disk (written by OTr_SaveToXMLFile) and loads it into a new OTr handle using DOM parsing.

Returns 0 if the file does not exist or contains invalid XML.

Delegates all parsing to OTr_LoadFromXML, including BOM stripping.

Parameters

ParameterTypeDirectionDescription
inFilePathText➡️Full path of the source file
ResultInteger⬅️New OTr handle, or 0 if loading failed
