OTr_LoadFromBlob

ObjectTools equivalent: OT LoadFromBlob

OTr_LoadFromBlob (inBlob) --> Longint

Shared, Invisible, Preemptive indifferent

Changed behaviour

The output format of this method differs from the ObjectTools plugin equivalent. Text or BLOBs produced by one are not compatible with the other. See the description below for details.

Loads an object from a 4D-native blob (written by OTr_SaveToBlob) into a new OTr handle. The blob is expanded automatically if it is compressed before reading via BLOB TO VARIABLE.

Returns 0 if the blob is empty or cannot be decoded.

NOTE: there is no equivalent Object Tools command

Parameters

ParameterTypeDirectionDescription
inBlobBlob➡️Compressed 4D-native blob \
ResultInteger⬅️New OTr handle, or 0 if loading failed
