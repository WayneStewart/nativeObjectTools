OTr_CompareItems

ObjectTools equivalent: OT CompareItems

OTr_CompareItems (inSourceObject; inSourceTag; inCompareObject; inCompareTag) --> Longint

Shared, Invisible, Preemptive indifferent

Compares two items for equality. Both handles may be the same object.

Returns 1 if identical, 0 if not, -1 on error.

ORIGINAL DOCUMENTATION

OT CompareItems compares two items for equality. inSourceObject and inCompareObject may be the same object.

If either object handle is not valid, if either item does not exist, or if the two items do not have the same type, an error is generated, OK is set to zero, and -1 is returned.

Otherwise items are compared according to the rules of equality for equivalent variable types in 4D. Arrays are considered identical if they are the same size and corresponding elements are equal. BLOB and Picture items are considered identical if they contain the same bytes. Embedded objects are considered identical if each of their items are identical.
