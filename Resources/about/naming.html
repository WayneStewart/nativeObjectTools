OT → OTr naming

ObjectTools plugin methods used the prefix OT  with a space and mixed case. OTr replaces that prefix with OTr_. Most names translate directly; a few are new to OTr, and a few serialisation methods differ in behaviour from their plugin counterparts.

OTr only No ObjectTools 5.0 equivalent exists. Changed behaviour Method exists in both, but the output format differs — see the individual reference page before migrating.

— OTr_LoadFromText OTr only Parses a JSON string and stores the resulting object in a new OTr handle.
OT SaveToText OTr_SaveToText Changed behaviour Returns the stored object as a JSON string. Useful for inspection and testing.
OT LoadFromBlob OTr_LoadFromBlob Changed behaviour Loads an object from a 4D-native blob (written by OTr_SaveToBlob) into a new OTr handle. The blob is expanded automatically if it is compressed before reading via BLOB TO VARIABLE.
OT SaveToBlob OTr_SaveToBlob Changed behaviour Serialises the stored object to a compressed 4D-native blob using VARIABLE TO BLOB and GZIP compression. The format is 4D-internal and is not portable outside 4D. Use OTr_SaveToGZIP when portability across systems is required.
OT BLOBToObject OTr_BLOBToObject Changed behaviour Deserialises an OTr object from a BLOB previously made by OTr_ObjectToBLOB or OTr_ObjectToNewBLOB. A new handle is returned.
OT ObjectToBLOB OTr_ObjectToBLOB Changed behaviour Serialises an OTr object into a BLOB using VARIABLE TO BLOB with GZIP compression. The object's contents (including natively stored BLOBs and Pictures) are fully self-contained.
OT ObjectToNewBLOB OTr_ObjectToNewBLOB Changed behaviour Serialises an OTr object into a new BLOB and returns it as the function result. This is the recommended serialisation method because it avoids the by-reference BLOB parameter issues associated with OTr_ObjectToBLOB.
OT LoadFromFile OTr_LoadFromFile Reads a UTF-8 JSON file from disk and loads it into a new OTr handle. The file must have been written as a plain UTF-8 JSON text file (e.g. by OTr_SaveToFile).
OT SaveToFile OTr_SaveToFile Serialises the stored object to a UTF-8 JSON file on disk.
— OTr_LoadFromGZIP OTr only Loads an object from a GZIPed JSON blob (written by OTr_SaveToGZIP) into a new OTr handle. The blob is expanded and decoded as UTF-8 text before being parsed as JSON.
— OTr_SaveToGZIP OTr only Serialises the stored object to a UTF-8 JSON string and compresses it with GZIP, returning the result in a blob.
